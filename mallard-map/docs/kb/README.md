# Knowledge base: the project's memory

Claude doesn't remember between sessions. These notes do. Read them first each session, add what you learn, keep each
note short and sourced. Every claim is tagged **REAL** (measured birds), **DERIVED** (computed from REAL), **MODELED**
(statistical estimate), **REG** (regulation) or **REF** (reference/geography), and cites a source in `sources.md`.
Status words: **verified** = checked against a primary source; **secondary** = from news/aggregator sites, needs a
primary check; **approx** = location good to a few km.
