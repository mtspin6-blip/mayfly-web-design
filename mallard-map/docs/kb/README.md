# Knowledge base: the project's memory

Claude doesn't remember between sessions. These notes do. Read them first each session, add what you learn, keep each
note short and sourced. Every claim is tagged **REAL** (measured birds), **DERIVED** (computed from REAL), **MODELED**
(statistical estimate), **REG** (regulation) or **REF** (reference/geography), and cites a source in `sources.md`.
Status words: **verified** = checked against a primary source; **secondary** = from news/aggregator sites, needs a
primary check; **approx** = location good to a few km.

| File | What's in it |
|---|---|
| `sources.md` | Every source with link, license and what we used it for |
| `states/MT.md` | Montana summary: what we know, by region |
| `topics/season-and-zones.md` | 2026–27 dates, flyway and zone county lists |
| `topics/places.md` | Public waterfowl areas and duck water used to name hot spots |
| `topics/mallard-behavior.md` | What moves mallards (cold, freeze-up, food), with evidence type |
| `topics/hotspots.md` | Auto-generated audit of every hot spot on the map |
| `topics/estimated-paths.md` | How the estimated flight paths are made, results, limits |
| `topics/data-gaps.md` | What's missing, ranked |
